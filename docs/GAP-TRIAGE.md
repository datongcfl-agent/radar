# 缺口分诊

`gaps.md` 的“没有证据 / 单源待印证”是**信号**，不是**任务单**。

先选动作，再决定要不要搜：

1. **补来源**：模块确实属于本行业，只是缺证据；
2. **删模块**：模块不属于本行业，是被错误并入的；
3. **改 pack 边界**：模块属于相邻行业，应拆到另一个 pack。

## 反例：S24 智能厨房排油烟

- 它来自酒店弱电 18 系统清单；
- 更偏厨房/暖通设备，不是通用弱电主线；
- 把它留在 pack 里，`gaps.md` 就会提示“单源”，下一轮就会去搜“商用厨房排油烟”——这是让覆盖度指标反过来指挥领域。

正确动作：从 `packs/weak-current/pack.json` 删除 S24，而不是补来源。

## 规则

- 缺口清零 ≠ 完整；
- 不要为了把 `gaps.md` 变空而搜不相关来源；
- 删除模块也要重跑、更新基线，并在 PR 里说明为什么删。
